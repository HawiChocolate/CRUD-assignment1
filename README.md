# Food Bank App
A modern Flutter mobile application for managing food bank inventory.

## About the App
**Food Bank App** helps food banks and charities efficiently manage their food inventory. Users can browse available items, add new donations, edit existing stock, delete items, search the inventory, and view detailed information.

## Technologies Used
- Flutter: (Dart)
- Provider: for state management
- http: for API calls
- jsonplaceholder: as the mock backend API (`https://jsonplaceholder.typicode.com`)

## API Note
This app uses JSONPlaceholder (https://jsonplaceholder.typicode.com/posts) as a mock backend. Any data you add, update, or delete will not persist permanently as it is a fake API.
